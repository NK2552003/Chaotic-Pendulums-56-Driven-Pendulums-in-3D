# Chaotic Pendulums: 56 Driven Pendulums in 3D

A Pen created on CodePen.
Original URL: [https://codepen.io/editor/nk2552003/pen/01a10b1b-7479-72b9-bf30-2c12021d17f6](https://codepen.io/editor/nk2552003/pen/01a10b1b-7479-72b9-bf30-2c12021d17f6).

A WebGL (Three.js) simulation of dozens of driven pendulums whose pivots orbit an ellipse, each starting at a slightly different phase. They behave chaotically and leave glowing, fading trails. The equations are integrated with RK4.
